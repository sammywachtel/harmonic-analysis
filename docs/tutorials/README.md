# Tutorials — Learning-Oriented

Step-by-step lessons that get you from zero to working code.

## Available Tutorials

### 🚀 [Getting Started](getting-started.md)

**For:** First-time users
**Time:** ~15 minutes
**You'll learn:** Install the library, run your first chord-progression analysis, read confidence scores, try different style profiles.

### 🎧 [Audio Quick Start](audio-quickstart.md)

**For:** Users who want to analyze recordings
**Time:** ~5 minutes
**You'll learn:** Install the `[audio]` extra, run `analyze_audio_async` on a WAV/MP3, read the global key, chord events, region classification, and cadence info.

## Prerequisites

- Python 3.9+
- Basic command-line familiarity
- Some music-theory background helps but isn't required — concepts are introduced as they appear
